### Research

- [OpenVerdict ↗](https://vinroger.com/projects/openverdict): a 4B decision model that thinks in about 50 tokens. It returns a probability for every option, in one forward pass or after a short chain-of-thought.
  - Among the open models up to 9B that we tested, it is the most accurate or tied for first on **7 of 10** test sets.
  - **73.5%** on 540 BIG-Bench Hard and ProofWriter questions, with **53 tokens** of reasoning on average.
  <!-- At launch, add: [Model on Hugging Face](https://huggingface.co/vinroger/OpenVerdict-4B) · [Code on GitHub](https://github.com/vinroger/openverdict) -->
- [GitGlimpse ↗](https://www.vinroger.com/projects/gitglimpse): a search engine for GitHub pull requests, with an agentic retrieval loop that refines the query until a judge LLM accepts the answer.
  - Cross-encoder re-ranking raised MAP from **0.60 to 0.89** over 1,600 pull requests.
